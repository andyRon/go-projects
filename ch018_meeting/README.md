在线会议
---

基于golang、webrtc实现在线会议

### 核心技术栈

[Pion WebRTC](https://github.com/pion/webrtc)专门用于构建实时音视频通信（RTC）应用。是WebRTC 协议的 Go 语言实现。
使用案例

```shell
go get -u github.com/pion/webrtc/v3 
```






### 系统模块

- 会议管理
  - 会议列表
  - 会议创建
  - 会议编辑
  - 会议删除
- 用户管理
  - 登录
- WebRTC
  - 音视频通信
