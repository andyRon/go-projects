### 设计游戏架构

#### 游戏基本规则

斗地主游戏的基本规则包括：

- 三名玩家，其中一名为地主，其余两名为农民。
- 使用一副54张扑克牌（包括两张王）。
- 游戏目标是通过出牌，最先出完手中牌的玩家获胜。

#### 模块划分

将游戏分为以下几个模块：

- 牌管理模块：负责牌的生成、洗牌、发牌等操作。
- 玩家模块：管理玩家的手牌、出牌等行为。
- 游戏逻辑模块：处理游戏流程、牌型判断、胜负判定等。
- 用户界面模块：提供用户交互界面，显示游戏状态。
