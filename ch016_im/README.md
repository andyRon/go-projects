即时通讯系统
----
基于Gin、MongoDB的即时通讯系统

### 技术栈

Gin
MongoDB
Websocket

### 扩展安装

```shell
go get -u github.com/gin-gonic/gin
go get github.com/gorilla/websocket
go get go.mongodb.org/mongo-driver/mongo
go get -u github.com/golang-jwt/jwt/v4
go get github.com/satori/go.uuid
```
