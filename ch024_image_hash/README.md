### 图片相似度检测算法概述

图片相似度检测算法的核心任务是衡量两张图片在视觉内容上的相似程度。常见的算法包括：

- 直方图比较：通过比较图像的灰度或颜色直方图来评估相似度。
- 特征匹配：利用SIFT、SURF等特征提取算法，比较图像的关键点特征。
- 感知哈希（Perceptual Hashing）：通过生成图像的哈希值来快速比较相似度。


### 感知哈希算法原理

感知哈希算法的核心思想是将图像转化为一个简化的哈希值，相似图像的哈希值应当相近。具体步骤如下：

1. 图像缩放：将图像缩放到统一大小，通常是8x8或16x16。
2. 灰度化：将彩色图像转换为灰度图像。
3. 计算平均值：计算灰度图像所有像素的平均值。
4. 生成哈希值：将每个像素与平均值比较，大于平均值记为1，小于等于平均值记为0，最终生成一个二进制哈希值。


### 概念

汉明距离（Hamming Distance）是用于比较两个等长字符串之间差异程度的度量方法，计算的是两个字符串在相同位置上不同字符的个数。在图像处理中，常用于比较图像哈希值的相似度。
